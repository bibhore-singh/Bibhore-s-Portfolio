The Old Way: One Article at a Time

Traditional tools flag individual articles, causing both false alarms and missed fakes.

Problems with this approach:
  • Satire/humor gets falsely flagged as fake news
  • Fake news creators bypass filters by rewording headlines
  • No memory of a source's past behavior
  • High false positive rate silences legitimate journalists

🎯

Our Way: Track the Publisher's Honesty

FAKEBUSTER monitors multiple articles from the same source to build a trust score over time.

Why this is smarter:
  • Satire sites get flagged based on their overall track record
  • Serial fake news websites are caught even if articles are reworded
  • Trust score improves with each verified article
  • Social feed reach is automatically reduced for low-trust sources

How the AI Works

Why We Chose This Fast & Smart AI Model

Hover over each card to flip it and read the technical detail behind each behaviour.

01

Stays Calm When Right

When the AI correctly classifies a story, it doesn't change anything.

👆 Hover / tap to see how
TECHNICAL DETAIL

When hinge loss = 0 (correct prediction), the model weights w remain unchanged — zero compute wasted. This is the "passive" mode.

if loss == 0: w = w # passive
02

Learns Fast When Mistaken

If it gets tricked by a new fake news style, it updates immediately.

👆 Hover / tap to see how
TECHNICAL DETAIL

When hinge loss > 0, weights are updated with the minimum norm change: w = w + τ·y·x. This is the "aggressive" update — swift, targeted correction.

if loss > 0: w += τ * y * x # aggressive
03

Instant Speed

Packaged for real-time checking in under 2 milliseconds per article.

👆 Hover / tap to see how
TECHNICAL DETAIL

TF-IDF sparse matrix multiplication is O(n) in the vocabulary size. Persisted as model.pkl + vector.pkl — loaded once at Flask startup, serving every request in <1.4ms.

latency: 1.4ms · pkl: model + vector
